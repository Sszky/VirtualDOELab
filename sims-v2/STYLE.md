# Virtual DOE Lab — Style Guide

แนวทางหน้าตาของเว็บ ใช้เป็นหลักเวลาแก้หน้าเดิมหรือเพิ่มการทดลองใหม่ ให้ทุกหน้าดูเป็นชุดเดียวกัน

ค่าทุกตัวในไฟล์นี้มาจากโค้ดจริง ถ้าแก้ CSS แล้วค่าเปลี่ยน ให้แก้ไฟล์นี้ตามด้วย

| ไฟล์ | หน้าที่ |
|---|---|
| `assets/site.css` | สี ฟอนต์ navbar ปุ่ม ใช้ทุกหน้า |
| `home.css` | หน้าแรก |
| `assets/sim.css` | โครงหน้าการทดลอง (โซน A / โซน B) ใช้ร่วมกันทั้ง 4 การทดลอง |
| `<การทดลอง>/style.css` | เฉพาะตัวละครในฉากของการทดลองนั้น เช่นตัวจรวด ตัวร่ม |
| `assets/icons.svg` | ต้นฉบับชุดไอคอน (ฝังไว้ในทุกหน้า) |
| `assets/iso3d.js`, `assets/home-art.js` | ภาพ isometric หน้าแรก |
| `assets/effects-chart.js` | กราฟ Main Effects / Interaction ของทั้ง 4 การทดลอง (แกน Y, error bar, tooltip, PNG) |
| `assets/table-settings.js` | ปุ่มเฟืองเลือกคอลัมน์ของตารางย่อ |

## 1. อารมณ์และหลักการ

**ธีม "Blueprint Tech"** — ห้องแล็บวิศวกรรม กระดาษเขียนแบบ เฟือง โรงงาน ดูเป็นเครื่องมือจริงที่ใช้เรียน ไม่ใช่เว็บโฆษณา

กฎที่ต้องทำตามทุกหน้า:

1. **ไม่ใช้อิโมจิ** ทั้งในหน้าเว็บ ข้อความแปล และปุ่ม ใช้ไอคอนเส้นจากชุดไอคอนแทน
2. **ไม่มีโหมดมืด** เว็บมีลุคเดียว ไม่ต้องเขียน `prefers-color-scheme`
3. **ภาษาเริ่มต้นเป็นอังกฤษ** สลับเป็นไทยได้ และภาษาที่เลือกใช้ทั้งเว็บ (ดูข้อ 9)
4. **ขยับเฉพาะตอนผู้ใช้ทำอะไร** เช่น hover กด เลื่อน ไม่มีอะไรวิ่งเองตอนเปิดหน้า
5. **ไม่ให้ดูเหมือน AI ทำ** หลีกเลี่ยง gradient ม่วง-ชมพู การ์ดมีกรอบซ้อนกรอบ ไอคอนกลมๆ ในวงกลมสีอ่อนเรียงกันเป็นแถว และคำโฆษณาเกินจริง
6. ใช้ **โทเคนสี** (`var(--blue)` ฯลฯ) เสมอ ไม่พิมพ์รหัสสีลงไปตรงๆ ในหน้าใหม่

### สีกราฟ (Main Effects / Interaction)

กราฟวาดด้วย `effects-chart.js`: แกนสีกรมท่า เส้นกริด `--line` ตัวเลข `--muted` ชื่อแกน `--ink` จุดเป็นวงกลมพื้นขาวขอบสีเส้น error bar เส้นบาง 1.5px มีขีดปลาย


สีเส้น 7 สี เรียงตามลำดับช่องที่ 1–7: น้ำเงิน แดง เขียวอ่อน ชมพู เหลือง เขียวเข้ม ส้ม

`#2563eb` · `#dc2626` · `#65a30d` · `#db2777` · `#ca8a04` · `#166534` · `#ea580c`

- **ล็อกสี:** ค่าของปัจจัยจัดกลุ่มได้ช่องสีตามลำดับที่ปรากฏในประวัติการทดลองครั้งแรก ไม่ใช่ตามลำดับค่า เพิ่มเส้นใหม่แล้วเส้นเดิมต้องไม่เปลี่ยนสี (legend ยังเรียงตามค่า) กด Clear แล้วเริ่มนับใหม่
- **เกิน 7 เส้น:** วนสีเดิม ช่อง 8–14 เป็นเส้นประยาว `8 5` ช่อง 15 ขึ้นไปเป็นประถี่ `3 4` (error bar และวงจุดเป็นเส้นทึบเสมอ)
- legend ใช้ขีดเส้นสั้นที่มีลายเดียวกับเส้นในกราฟ ทั้งบนหน้าเว็บและในรูป PNG

## 3. ตัวอักษร

| บทบาท | ฟอนต์ | หมายเหตุ |
|---|---|---|
| หัวข้อ ปุ่ม navbar ตัวเลขเด่น | **Chakra Petch** 500/600/700 | `--font-display` ดูเป็นเทคนิค เหลี่ยมนิดๆ |
| เนื้อหา ข้อความไทย | **IBM Plex Sans Thai** 400/500/600 | `--font-body` |

โหลดจาก Google Fonts ทั้งคู่ ทั้งสองฟอนต์มีภาษาไทย

| ที่ใช้ | ขนาด |
|---|---|
| หัวข้อ hero | `clamp(3rem, 10.5vw, 9.5rem)` ตัวพิมพ์ใหญ่ น้ำหนัก 700 บรรทัดชิด 0.92 |
| หัวข้อส่วน (Four Simulators) | `clamp(2rem, 4.4vw, 3.4rem)` ตัวพิมพ์ใหญ่ |
| หัวข้อโซน B | `clamp(1.35rem, 2.4vw, 1.9rem)` |
| หัวข้อการ์ด/แผง | `1.05rem` น้ำหนัก 700 |
| เนื้อหา | `16px` บรรทัด 1.5 |
| label ช่องกรอก | `0.86rem` น้ำหนัก 600 |
| ข้อความเล็ก ช่วงค่า | `0.74rem` สี `--muted` |
| eyebrow (ข้อความเล็กเหนือหัวข้อ) | `0.85rem` ตัวพิมพ์ใหญ่ ห่างตัวอักษร `0.2em` สีน้ำเงิน |

- หัวข้อใช้ `text-wrap: balance`

## 4. ระยะ มุมมน เงา

| สิ่งของ | มุมมน |
|---|---|
| การ์ดลอยในโซน A | `16px` (`--card-radius`) |
| ค่ามุมมนทั่วไป | `14px` (`--radius`) |
| ปุ่มหลัก ตัวเลือก segmented | `10px` |
| สัญลักษณ์ navbar | `10px` |
| ปุ่มรอง ช่องกรอก ลิงก์ navbar | `8px` |
| แถบผลลัพธ์ ปุ่มบอกเลื่อน | `999px` (ทรงแคปซูล) |
| **กล่องกราฟโซน B** | **`0` (เหลี่ยม)** |

เงา:

- การ์ดลอย: `0 18px 40px rgba(11,28,51,.18), 0 2px 6px rgba(11,28,51,.08)` (`--card-shadow`)
- เมนู dropdown: `0 18px 40px rgba(11,28,51,.16)`
- ภาพ isometric: `drop-shadow(0 18px 16px rgba(11,28,51,.16))` ตอน hover ลอยขึ้น 10px และเงาเข้มขึ้น

เงาใช้สีกรมท่าโปร่งเสมอ ไม่ใช้สีดำล้วน

ระยะขอบหน้าใช้ `clamp(16px, 3vw, 36px)` (มือถือขั้นต่ำ 16px) ช่องว่างระหว่างคอลัมน์ `20px`

## 5. โครงหน้า

### Navbar (ทุกหน้า)

- สูง `64px` (มือถือ `58px`) ติดขอบบน พื้นขาว เส้นล่าง `--line`
- ซ้าย: สัญลักษณ์เฟืองบนสี่เหลี่ยมกรมท่า + "Virtual DOE Lab" / "For Industrial Engineering"
- ขวา: Simulators (dropdown) · ปุ่มภาษา (`TH`/`EN` ขอบกรมท่า) · **Home ขวาสุด** (ใกล้นิ้วโป้งขวาบนมือถือ)
- มือถือ (≤600px): ซ่อนชื่อเว็บและคำว่า Home เหลือแค่สัญลักษณ์และไอคอนบ้าน แถบซ่อนตอนเลื่อนลง โผล่ตอนเลื่อนขึ้น
- ลำดับการทดลองในเมนู: **Water Bottle Rocket → Catapult → Paper Helicopter → Parachute** (จรวดก่อน ที่เหลือเรียง A–Z) ต้องตรงกับหน้าแรก

### หน้าแรก

1. **Hero** เต็มจอ พื้นกรมท่า มีกริดกระดาษเขียนแบบ (`--sky-accent` โปร่ง 13% ช่องละ 160px ย่อย 32px) จางลงด้านล่าง
   - หัวข้อ "VIRTUAL **DOE** LAB" คำว่า DOE เป็นสี `--sky-accent`
   - เครื่องมือ isometric 9 ชิ้น (กรรไกร ขวด ตลับเมตร ลูกปิงปอง นาฬิกาจับเวลา คัตเตอร์ เทปกาว หลอดด้าย ม้วนกระดาษ) กระจายรอบหัวข้อ
   - ขอบล่างเป็น **ฟันเฟืองขนาดใหญ่เต็มความกว้าง**
   - ปุ่ม "Choose an experiment" พาเลื่อนลงไปที่หัวข้อการทดลอง
2. **การทดลอง 4 อัน** — การ์ด **ไม่มีกรอบ** มีแค่ภาพ isometric บนแท่นหญ้า + ชื่อ + คำอธิบายสั้น + "Start experiment →"
   - 4 คอลัมน์ → 2 คอลัมน์ (≤1000px) → 1 คอลัมน์ (≤560px)
3. **Footer** พื้นกรมท่า ด้านบนเป็นเงาโรงงาน (skyline)

### หน้าการทดลอง: 2 โซน

**โซน A — Experiment** (สูงเต็มจอ)
- พื้นหลังเป็นฉากเดียวเต็มโซน: ท้องฟ้าไล่สี → เส้นขอบฟ้า → หญ้า มีใบหญ้าเรียงตามขอบฟ้าและลายตัดหญ้าจางๆ
- เส้นขอบฟ้าต้องตรงกับเส้น 0 m ในฉาก (`app.js` คำนวณให้เองผ่าน `--horizon`)
- 3 คอลัมน์: **แผงปัจจัย** (320px) · **ฉากจำลอง** (โปร่ง วาดบนพื้นหลังตรงๆ) · **ตารางผล** (330px)
- แผงปัจจัยและตารางเป็น **การ์ดลอย** ขาวทึบ มุมมน 16px มีเงา
- แถบผลลัพธ์รอบล่าสุดเป็นแคปซูลขาวลอยในฉาก
- ด้านล่างมีปุ่มแคปซูลกรมท่าโปร่ง "Analysis charts" บอกให้เลื่อนลง

**โซน B — Analysis**
- พื้นเรียบ `--bg` **ไม่มีการ์ดลอย ไม่มีเงา**
- กล่องตัวเลือกกราฟ (320px) และกล่องกราฟ ใช้ **เส้นกรอบเดียว** `1.5px solid var(--navy)` มุมเหลี่ยม (`.box-line`)

**การเลื่อนระหว่างโซน**
- จอกว้าง (>900px): CSS `scroll-snap-type: y mandatory` ดูดเข้าโซนละหน้าจอ
- จอแคบ (≤900px): ปิด CSS snap และใช้ `assets/zone-snap.js` ดูดเข้าโซนกราฟเฉพาะตอนผู้ใช้เลื่อนลงเอง โซน A สูงตามเนื้อหา เรียงเป็น ฉาก → แผงปัจจัย → ตาราง

### Breakpoints

| ความกว้าง | สิ่งที่เปลี่ยน |
|---|---|
| ≤1180px | คอลัมน์โซน A แคบลง (290 / 300px) |
| ≤1000px | การ์ดหน้าแรก 2 คอลัมน์ |
| ≤900px | หน้าการทดลองเป็นคอลัมน์เดียว เปลี่ยนจาก CSS snap เป็น JS snap |
| ≤600px | navbar แบบมือถือ ตัวอักษรและระยะเล็กลง |
| ≤560px | การ์ดหน้าแรก 1 คอลัมน์ |

ทุกหน้าต้องไม่มี scroll แนวนอนที่ความกว้าง 360px

## 6. ส่วนประกอบ

| ส่วนประกอบ | หน้าตา |
|---|---|
| **ปุ่มหลัก** (`.primary-button`) | กว้างเต็ม พื้นน้ำเงิน ตัวขาว มุม 10px ฟอนต์ display hover เข้มขึ้น กดแล้วจมลง 1px ตอนกำลังจำลองเปลี่ยนเป็น `--navy-2` |
| **ปุ่มรอง** (`.secondary-button`) | พื้นขาว ขอบ `--line` 1.5px hover ขอบและตัวอักษรเป็นน้ำเงิน ใช้กับ Export CSV ล้างตาราง ขยายตาราง |
| **ปุ่มภาษา** (`.nav-lang`) | ขอบกรมท่า 1.5px hover กลับสีเป็นพื้นกรมท่าตัวขาว |
| **ช่องปัจจัย** | slider (`accent-color: --blue`) คู่กับช่องตัวเลขกว้าง 70px บอกช่วงค่าเป็นตัวเล็กสีเทาข้าง label |
| **ตัวเลือกแบบปุ่มคู่** (`.segmented`) | กล่องพื้น `--bg` ตัวที่เลือกเป็นพื้นกรมท่า ใช้กับ Deterministic/Stochastic และปัจจัยแบบตัวเลือก |
| **กล่องคำเตือน** | ขอบแดง 1px พื้นแดงโปร่ง 8% มุม 8px |
| **ตารางผล** | ย่อไว้ในการ์ด กดขยายเป็น modal กลางจอ (พื้นหลังกรมท่าโปร่ง 50%) ทุกขนาดจอ · ค่าและหัวคอลัมน์จัดกึ่งกลาง · สีสลับคอลัมน์ คี่ขาว คู่เทาอ่อน `--col-alt` `#f1f5f9` (ตารางย่อนับเฉพาะคอลัมน์ที่แสดง) · แถวที่ชี้เป็น `--blue-50` |
| **Dropdown** | พื้นขาว ขอบ `--line` มุม 12px เงา รายการที่เปิดอยู่เป็นพื้นกรมท่า |
| **ตั้งค่าคอลัมน์** | ปุ่มเฟือง 32px ข้าง "Run history" (ซ่อนตอนตารางขยาย) เปิดการ์ดลอยกลางจอกว้าง ≤380px หลังเป็นฝ้าแบบตารางขยาย กลุ่ม Factors / Results เป็น checkbox (หัวกลุ่มตัวพิมพ์ใหญ่สีน้ำเงิน) ล่างสุด Reset + Done มีผลเฉพาะตารางย่อ ต้องเหลืออย่างน้อย 1 คอลัมน์ |
| **Tooltip กราฟ** | พื้นกรมท่า ตัวขาว `0.76rem` มุม 8px ลอยเหนือจุด ไม่ล้นขอบการ์ด |

Focus ของคีย์บอร์ดใช้ `outline: 3px solid var(--blue)` ห่าง 2px ทุกที่ ห้ามลบทิ้ง

## 7. ไอคอน

- เป็น **ไอคอนเส้น** viewBox `0 0 24 24` เส้นหนา `2` ปลายมน ใช้สี `currentColor` เพื่อให้เปลี่ยนสีตามตัวอักษร
- ขนาดปกติ `1.15em` (class `.icon`) ในเมนู 20px ในปุ่มรอง 16px
- ต้นฉบับอยู่ที่ `assets/icons.svg` แต่ **ฝัง sprite ไว้ในทุกหน้า** แล้วเรียกด้วย `<use href="#i-ชื่อ"/>` เพราะในตัวแสดง artifact บน iPhone การโหลดจากไฟล์แยกไม่แสดงผล
  - ถ้าเพิ่มไอคอนใหม่ ต้องเพิ่มทั้งใน `icons.svg` และใน sprite ของทุกหน้า
- ไอคอนประจำการทดลอง: `i-sim-rocket`, `i-sim-catapult`, `i-sim-helicopter`, `i-sim-parachute`
- **Favicon:** เฟืองทึบสี `#0b1c33` มีขอบขาวบาง (ให้เห็นบนแท็บโหมดมืด) ฝังเป็น `data:` URI ใน `<head>` ทุกหน้า ใช้รูปทรงเดียวกับ `i-gear`

## 8. ภาพประกอบ

### ภาพ isometric (หน้าแรก)

- วาดด้วย `iso3d.js` เป็น **low-poly แบบ isometric** ออกมาเป็น SVG polygon สีทึบ ไม่ใช้ไฟล์ภาพ
- แสงมาจากด้านซ้ายบน หน้าบนสว่างสุด ด้านซ้ายกลาง ด้านขวามืด (ambient 0.5 + diffuse 0.55)
- การทดลองแต่ละอันตั้งบน **แท่นหญ้าสี่เหลี่ยม** มีดินด้านข้าง
- **ไม่มีกรอบ ไม่มีพื้นหลัง** รอบภาพ
- ขยับเฉพาะตอน hover/focus (ลอยขึ้นและแสดงท่าทางของการทดลองนั้นสั้นๆ)
- จานสีหลักใน `home-art.js`: หญ้า `#7cc26b` · ดิน `#a0703f` · ไม้ `#c8904f` · ท่อ PVC `#4cb8ea` · กระดาษ `#fbf7ec` · โลหะ `#cbd5e1` · กรมท่า `#1b3a6b` · น้ำเงิน `#2563eb` · เหลืองอำพัน `#f59e0b`

### ฉากจำลอง (หน้าการทดลอง)

- วาดด้วย SVG/Canvas แบบ 2D ด้านข้าง บนพื้นหลังท้องฟ้า-หญ้าของโซน A
- มีดวงอาทิตย์และเมฆเป็นของตกแต่ง
- แกนและป้ายตัวเลขใช้สี `--muted` ตัวเล็ก (`0.68rem`) บนป้ายขาวโปร่ง
- การทดลองแบบตกลงมา (ร่ม เฮลิคอปเตอร์) มีแค่แกน Y และไม่มีเงาของรอบก่อน
- ท่าทางระหว่างตก: ร่มแกว่ง ±3° · เฮลิคอปเตอร์หมุนทั้งตัวรอบแกนตั้ง (บีบตาม cos ของมุม เห็นอีกด้านเป็นสีกระดาษเข้มกว่า) และส่ายแรง ~8° ช่วงใบพัดเริ่มหมุน แล้วลดเหลือ ~3° หมุนรอบจุดบนสุด

## 9. ภาษา

- ข้อความทุกตัวในหน้าต้องมี `data-i18n="key"` และมีคำแปลทั้ง `en` และ `th` ใน `i18n.js` ของหน้านั้น
- คำแปลของ navbar อยู่ใน `nav.js` ไม่ต้องใส่ซ้ำในแต่ละหน้า
- ภาษาที่เลือกจำไว้ทั้งเว็บด้วย `getSiteLang()` / `setSiteLang()` ใน `nav.js`
  - เก็บใน localStorage (`vdoe-lang`)
  - ต่อท้าย `?lang=th` ให้ลิงก์ในเว็บด้วย เผื่อเครื่องที่ใช้ localStorage ไม่ได้
- ชื่อการทดลองภาษาไทย: จรวดขวดน้ำ · เครื่องยิงหิน · เฮลิคอปเตอร์กระดาษ · ร่มชูชีพ
- เขียนข้อความให้สั้น ตรง เป็นภาษาที่ใช้ในห้องแล็บ ไม่ใช้คำโฆษณา

## 10. การเคลื่อนไหว

| สิ่งที่ขยับ | ระยะเวลา |
|---|---|
| สีปุ่ม/ลิงก์ตอน hover | `0.15s ease` |
| ลูกศร dropdown หมุน, ลูกศร "Start experiment" เลื่อน 4px | `0.2s ease` |
| ภาพ isometric ลอยขึ้นตอน hover | `0.28s ease` |
| navbar ซ่อน/โผล่บนมือถือ | `0.25s ease` |
| ปุ่มบอกเลื่อนลงกระตุก 3px ตอนกด | `0.6s` ครั้งเดียว |
| แอนิเมชันการทดลอง | ตามเวลาจริงจากผลการจำลอง |

- ไม่มีอะไรวนลูปเอง
- รองรับ `prefers-reduced-motion: reduce` ปิด transition และ animation ทั้งหมด
